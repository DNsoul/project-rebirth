Rebirth for Windows: what is in the tunnel
==========================================

Rebirth carries its own tunnel in the "tunnel" folder next to Rebirth.exe, so that
nothing else has to be installed:

  tunnel\awgtunnel.exe      the tunnel service, built from the open-source libraries
                            listed below
  tunnel\wintun.dll         the network adapter driver library of Wintun, unmodified,
                            from https://www.wintun.net/ (Wintun 0.14.1)
  tunnel\wintun-LICENSE.txt the licence of that file
